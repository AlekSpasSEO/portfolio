# Aleksandar Spasevski — Portfolio

A responsive one-page portfolio with career history and expandable client work, including Shkrtka.

**Live:** https://alekspasseo.github.io/portfolio/

Built with HTML, CSS, and JavaScript. No dependencies, build step, analytics, or cookies. Content and links work without JavaScript. GIF playback and clipboard controls use it when available.

## Preview

From this directory run `node preview.mjs`, then open http://127.0.0.1:4190/.

## Update

- `index.html`: career history, client work, skills, and contact details.
- `styles.css`: layout, typography, and responsive styles.
- `app.js`: site tour playback, email clipboard action, and copyright year.
- `client-logos/`: client wordmarks.
- `client-previews/`: still and animated screenshots of the featured websites.

Career scope and outcomes are based on the CV. The Drip Hydration chart credits the vendor's public case study, and search examples are dated observations.

## Publish

GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`. Commits to `main` deploy automatically.
