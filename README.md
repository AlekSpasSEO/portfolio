# Aleksandar Spasevski — Portfolio

A responsive one-page portfolio covering all roles and accomplishments from the supplied 2026 CV, plus Shkrtka, Sevo, Kroshna, Od Ponedelnik, and Staro Kupujem.

**Live:** https://alekspasseo.github.io/portfolio/

Built with HTML, CSS, and JavaScript. No dependencies, build step, analytics, or cookies. Core content and links work without JavaScript; a clipboard button is progressively enhanced when available.

## Preview

From this directory run `node preview.mjs`, then open http://127.0.0.1:4190/.

## Update

- `index.html`: career history, project descriptions, skills, and contact details.
- `styles.css`: layout, typography, and responsive styles.
- `app.js`: email clipboard action and copyright year.
- `shkrtka.jpg`, `sevo.jpg`, `staro.jpg`: project website screenshots.

Kroshna's original canopy mark is included in the project preview. The directory and marketplace projects are explicitly presented as demos. Career dates, scope, and outcome figures are drawn from Aleksandar's supplied CV; revenue results retain their approximate qualifiers and business context.

## Publish

GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`. Commits to `main` deploy automatically.
